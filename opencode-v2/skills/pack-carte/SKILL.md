# /outil carte

Started directly as the command `/pack-carte` (this procedure is the message that started you, with no line « Skill : pack-carte » printed before it): answer only « Lance `/outil carte` : cette procédure a besoin de ce que /outil prépare. » and stop.

The page is already written by `pack-map.sh`: its « CARTE: » line above gives its file and what it counts; one line per command (« COMMANDE: »), agent, skill, function of the plugin and tool of /outil follow. A « STOP: » line or a « Carte : … rien n'est écrit » line instead: answer with it in one French sentence, and stop. Never read the files of the pack again, never rebuild or edit the page: it is regenerated by `/outil carte`, from the pack as it is installed.

Answer in French, from these lines only:
- « 🗺️ Carte des flux : `<the file of the CARTE line>` », then how to open it: written in the configuration folder of OpenCode (no argument), it is a file of the machine of OpenCode: on that machine, a double click (`open <file>` on macOS, `xdg-open <file>` on Linux); when OpenCode runs on another machine (its web interface), copy it to yours (`scp <machine>:<file> .`) or write it in the repository with `/outil carte docs`; written in the repository (a path was given), it goes with `/push`, then opens from a clone on any computer (or downloaded from GitLab).
- What it holds, in one line: the counts of the CARTE line, and that it starts with « En une minute » and the map of the whole, for someone who never used the pack.
- The commands, one table | Commande | À quoi elle sert | Qui travaille | Ses questions |, from the COMMANDE lines in their order: the plain sentence, the agents (the agent of the command when it calls none), the questions (« — » when none).
- One line for the tools of /outil (their names, from the OUTIL lines), one for the guardrails: « <n> garde-fous du plugin, dont » the functions 7, 9 and 25 when they are listed, in a few words each.
Never a value of a configuration, never a path of another repository.

Last, the « Suite » question: « /outil carte docs » (« l'écrire dans docs/ du dépôt, pour la pousser et la partager »; only when the page was written in the folder of the pack), « Rien pour l'instant ».
