# /outil liens

Started directly as the command `/pack-liens` (this procedure is the message that started you, with no line « Skill : pack-liens » printed before it): answer only « Lance `/outil liens` : cette procédure a besoin de ce que /outil prépare. » and stop.

The pack already ran `related-setup.sh scan` (the lines above): THIS (this repository and what it is), DECLARED (the related repositories AGENTS.md names, found or not, and how), REFERENCE (the references of opencode.json of this machine), CANDIDATE (the git repositories next to it, what links each to this one — a package of one used by the other, the same Jira projects in their commits, a common name, the local port of the API called by the front — declared or not, reference or not) and ROLES. The files change only through `related-setup.sh`: never the edit tool on AGENTS.md or opencode.json, never another repository by hand.

1. No CANDIDATE and nothing DECLARED: answer that no other git repository sits next to this one (`<parent folder>`), that `/go … comme dans <dossier>` or a path typed in a message makes a folder readable for one session, and the « Suite » question « Rien pour l'instant ». Stop.
2. ONE question tool call (the wizard, one step), its questions together:
   - for each CANDIDATE with evidence and each DECLARED one (6 at most, the strongest evidence first), header its name (12 characters at most), question « <name> (<what it is>, <path>) : <evidence> — son rôle pour <this repository> ? », options: the role ROLES suggests for this pair of kinds, written for it (« Le front Angular qui appelle cette API (recommandé) », « La librairie Acme.Montants que ce dépôt utilise (recommandé) »…), one other plausible role, « Pas lié à ce dépôt »; a DECLARED one: its current role first (« Garder : <its role> (recommandé) »), then « Ne plus le déclarer ». The developer may type the role in his words.
   - header « Lecture », `multiple: true`: « Quels dépôts les agents peuvent-ils lire (code, en lecture seule) ? », one option per repository of the questions above, the ones with evidence recommended (« référence d'opencode.json de cette machine : /go lit son code, ses contrats ; jamais une écriture »), and « Aucun ».
   - header « Réciproque », `multiple: true`: « Dans quels dépôts j'écris aussi la ligne qui nomme <this repository> (son AGENTS.md, non commité) ? », one option per repository of the questions above (recommended: « chacun nomme l'autre : c'est ce qui fait la même application »), and « Aucun ».
   A CANDIDATE without any evidence is never asked: it is listed in the answer (« trouvé sans lien visible »), so that the developer may run `/outil liens` again after naming it in a message.
3. ONE shell call, the commands joined with ` && `, one per repository kept: `sh ~/.config/opencode/scripts/related-setup.sh apply <name> <its path as CANDIDATE gives it> "<its role>"[ --reference][ --reciprocal "<the role of this repository seen from there>"]`; one per repository « Pas lié » or « Ne plus le déclarer » that is DECLARED: `sh ~/.config/opencode/scripts/related-setup.sh remove <name>[ --reference, when it is a REFERENCE]`. The reciprocal role mirrors the role: « le front Angular qui appelle cette API » ↔ « l'API .NET que ce front appelle »; « la librairie <package> que ce dépôt utilise » ↔ « un dépôt qui utilise cette librairie (paquet <package>) ». A "STOP:" line (a path that cannot be read safely: the home folder, a hidden folder, a folder of the system, not a git repository): say it in one sentence, nothing was changed for that repository.
4. The answer, in French: a table | Dépôt | Rôle | Lecture par les agents | Ligne réciproque |, from the lines AGENTS.md:, OPENCODE.JSON:, RECIPROCAL: and RELATED: of the call; then what to do: « Redémarre OpenCode » when a reference was written (its RESTART line: OpenCode reads its references at its start; the agents then read that code, never write there); the AGENTS.md changed here and, for a reciprocal line, the other repository's own (each goes with its own /push); the copy of opencode.json saved before the change (its path). Last, the « Suite » question: « /push (recommandé) » (« l'AGENTS.md de ce dépôt dans un commit, avec sa MR »), « Rien pour l'instant ».
